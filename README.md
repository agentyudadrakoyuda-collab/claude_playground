# claude_playground
Playground for experimenting with prompts, structures, and ideas using Claude.

## Track Replay

`track-replay/` is a phone-friendly GPS track player. It replays KMZ/KML/GPX drives on a
street map (OpenFreeMap / OpenStreetMap), races two drives with KPIs and splits, plans
virtual redos, draws new routes along roads (OSRM), records new tracks with the phone's
GPS, and reverses routes. Open it at `/track-replay/` on the GitHub Pages site.
